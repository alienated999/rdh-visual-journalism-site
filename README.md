# RDH Visual Journalism site

Standalone newsroom site: Home, Work, Coon Rapids 131st Street fire gallery, Prevention, About, Contact.

## Live this folder

GitHub Pages: Settings → Pages → Deploy from branch `main` → / (root).

Or unzip and upload to Netlify / your host. Point www.RDHVISUALJOURNALISM.com at that host.

Replace the gray boxes with the four fire JPEGs and one About portrait before you call it published.
